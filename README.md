# 🍫 Chocolate Industry Sales Dashboard

## 📊 Project Overview

This project is an interactive **Chocolate Industry Sales Dashboard** developed using Microsoft Excel.

The dashboard provides a visual analysis of sales and profit performance across different countries, products, months, quarters, and years.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

The dashboard includes:

- Country-wise Sales Analysis
- Country-wise Profit Analysis
- Product-wise Sales Analysis
- Product-wise Profit Analysis
- Month-wise Sales Trends
- Quarter-wise Sales Analysis
- Total Revenue
- Total Profit
- Interactive Country Filter
- Interactive Product Filter
- Year Filter
- Month Filter
- Quarter Filter

## 🔍 Key Metrics

The dashboard displays:

- Total Revenue: $82,77,489.00
- Total Profit: $48,77,074.75

## 🎯 Project Objective

The main objective of this project is to transform raw chocolate sales data into an interactive dashboard that helps users understand sales performance, profitability, product performance, and business trends.

## 💡 Key Insights

The dashboard allows users to:

- Compare sales performance across countries.
- Identify profitable products.
- Analyze monthly and quarterly sales trends.
- Compare revenue and profit.
- Filter the dashboard based on country, product, year, month, and quarter.
